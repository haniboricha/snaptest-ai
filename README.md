# 🧪 SnapTest AI

> Transform UI screenshots into executable Playwright and Cypress automation test suites using Multimodal AI.

## 🚀 Features

- **Visual QA Parsing:** Upload form screenshots, UI mockups, or app designs (PNG/JPG).
- **Automated Test Generation:** Automatically generates happy path, edge case, and boundary condition test scenarios.
- **Instant Code Compilation:** Export directly to ready-to-run `.spec.ts` Playwright files.
